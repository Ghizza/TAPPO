# TAPPO 1.2.0 – Legacy

Questa cartella contiene la versione originale di TAPPO.

**TAPPO – Tool per Alleggerire PDF Pesanti Offline**

La versione originale permette di comprimere file PDF
utilizzando Ghostscript.

Questa versione è stata successivamente sostituita
da TAPPO 2.x, una riscrittura completa che supporta
la compressione di PDF e PNG.

La versione originale viene conservata per motivi
di compatibilità e per mantenere disponibile il
software agli utenti della prima release.
